## Project Overview

This project is a simple Laravel-based personal task management system designed to help users organize their daily work and responsibilities. It allows a user to create, view, update, and delete tasks, while also tracking each task's due date and current status.

The application is built using Laravel and SQLite, with Blade templates used for the user interface. It is meant to be lightweight, easy to understand, and practical for managing personal to-do lists.

### 1. Open the app
When the app starts, it opens the task page and shows all saved tasks.

### 2. Add a task
The user enters a task name, description, status, and due date. The form sends the data to the controller, and Laravel saves it in the database.

### 3. View tasks
The system reads all tasks from the database and displays them in a list. Tasks are sorted by due date, with pending tasks shown first.

### 4. Edit or update a task
The user can click edit to change the task details or update its status from Pending to Completed.

### 5. Delete a task
If a task is no longer needed, the user can delete it. The app removes it from the database and refreshes the list.
